Types of data

Environments

Photoshop documents with a brief, such as removing a background and placing the product on white, and a grader that checks the layers and the exported image.

For
Reinforcement learning with checkable rewards
Format
PSD files, task specs in JSON, one grader per task

Trajectories

Every tool, menu, and setting used, with the layer tree and a screenshot after each step, and the reason for it.

For
Fine-tuning and step-level rewards
Format
One JSON file per run, with layer state and a screenshot per step, plus before and after images

Human feedback

What a designer approved, retouched again, or rejected, with the change and the reason.

For
Preference training on visual quality
Format
One JSON line per review, with both images

Evals

Private editing tasks, refreshed every quarter, scored on the layer structure and the final image.

For
Clean measurement no model has trained on
Format
Run by us against your model; you get a scored report

One record

A trajectory is one JSON file, with the layer tree and a screenshot for every step, and the image before and after.

{
  "task": "Remove the background and place the product on a white canvas",
  "dataset": "photoshop",
  "workflow": "masking",
  "steps": [
    {
      "n": 4,
      "panel": "Layers · Product",
      "layers": "steps/0004.json",
      "screenshot": "steps/0004.webp",
      "action": "Select > Subject, then Add Layer Mask",
      "reason": "A mask hides the background and keeps the original pixels editable.",
      "progress": "advanced"
    }
  ],
  "images": {
    "before": "before.png",
    "after": "after.png"
  },
  "review": {
    "result": "approved",

    "checks_passed": 6,

  }

How a record is made

  1. Real work

    A designer or an agent edits an image in Photoshop, and a designer approves the result.

  2. Recorded

    Every tool, setting, and layer change is kept, with the image before and after.

  3. Cleared for use

    Faces, names, and client marks are replaced, or released by their owners.

  4. Graded

    The output is checked against the approved edit, layer by layer and pixel by pixel.

Privacy

  • Every image is licensed for training or made for the dataset.
  • No personal data is delivered. Faces and names are synthetic, or released by the people in them.
  • Client work is included only with written permission.
