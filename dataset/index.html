Types of data

Each dataset comes in some or all of these types.

Environments
The software, simulated, with tasks and a grader for each. For reinforcement learning.
Trajectories
Recorded runs, step by step: each screen, each action, and why. For fine-tuning.
Human feedback
What reviewers approved, changed, or sent back, and why. For preference training.
Evals
Private task sets, never published. You send a model; we send back scores.
