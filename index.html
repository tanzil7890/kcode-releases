This is KoraCode→

An agentic harness for the browser. Describe a web task from the terminal and it drives a real browser — step by step, in view, and asking before anything irreversible.

A browser agent you run from your terminal

Drives a real browser

Your own logged-in Chrome, or a cloud browser from Anchor, Browserbase, Hyperbrowser, Steel, or Kernel. Pick one with /browser.

Watch it work, live

The page the agent is on streams into a panel next to the chat, sharp in terminals with image support. Every step reads in plain words.

Your models

Bring an OpenAI, Anthropic, Google Gemini, xAI, OpenRouter, or DeepSeek key with /connect.

Asks before it acts

Purchases, sending messages, and deleting data need your yes first. Logins stay yours: you sign in, it carries on.

Scripts that compound

Working automations are saved in .kcode/agent-workspace/ and reused on later tasks.

Automate it

Run tasks headless with kcode run "…", or serve an HTTP API with kcode serve.

Long-running work, as a graphexperimental

Split a long browser task into steps you connect like a flowchart. Each step is a short agent session in one shared browser, and the run is saved after every step, so it picks up where it stopped after a crash, a restart, or a closed laptop.

List the invoices→ For each invoice→ Check the page→ AI decides→ overdueall paid

Build it on a canvas

kcode studio opens a node editor in your browser. Or ask the agent to turn the task it just did into a graph.

Picks up where it stopped

Every step's outcome is saved. A login, a captcha, or a decision pauses the run until you answer, then it carries on.

Cheaper every run

Finished steps become scripts that replay without AI. Schedules, batches, and kcode daemon run it with the terminal closed.

Get started

Best experience: iTerm2. KoraCode shows the live browser right next to the chat, and iTerm2 draws it as a sharp picture. On a Mac, download the stable iTerm2, open it, and continue below. VS Code's terminal works too with images turned on; macOS Terminal shows a lower-resolution preview.
  1. Install with the command above (in iTerm2 on a Mac), then open a new terminal.
  2. Run kcode in any folder.
  3. Connect a model with /connect.
  4. Pick a browser with /browser. A cloud browser works right away; for your own Chrome, turn on remote debugging at chrome://inspect/#remote-debugging.
  5. Tell it what to do. Try one of these:
